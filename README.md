# Desktop & Database Support

This repository demonstrates my practical SQL skills in database development, management, and troubleshooting environments.

The focus is on applying SQL to real-world technical support scenarios, including data investigation, query execution, database operations, issue reproduction, and result validation.

The scenarios use different database tools and environments, including Microsoft SQL Server Management Studio (SSMS) and Devart's dbForge tools.

**The primary focus is SQL proficiency and technical problem-solving, rather than any specific database tool.**

**Implementation:** A reproducible T-SQL demonstration covering database structure, data relationships, conditional logic, iterative processing, DML triggers, standard and recursive CTEs, and date/time operations.

**Validation:** Successfully executed in a dedicated SQL Server test environment. The case includes an executable SQL script, reproduction instructions, validation results, and execution evidence.
